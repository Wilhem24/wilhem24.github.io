# Paul Mbariro's Personal Portfolio

Welcome to my personal portfolio website! This project showcases my skills, projects, and background as a third-year Information Technology student at Chinhoyi University of Technology. It serves as a platform for potential employers, collaborators, and visitors to learn more about me, view my work, and get in touch.

## 🔍 Overview

The portfolio includes the following key sections:

- **Home:** A clean landing page introducing who I am.
- **About Me:** Details about my education, interests, and career goals.
- **Skills:** A categorized display of my technical and soft skills.
- **Projects:** Highlights of selected projects I've worked on.
- **Contact:** A simple contact form and links to my social profiles.

## 🚀 Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **Responsive Design** using Flexbox/Grid

## 📂 Folder Structure

```

portfolio/

│   └── style.css       # All custom styles
│
├── js/

```

## 📌 Features

- **Fully Responsive Design** – works on all devices (desktop, tablet, mobile).

- **Modular structure** for easy maintenance and future upgrades.
